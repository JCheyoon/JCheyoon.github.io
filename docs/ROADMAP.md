# 로드맵

**현재 단계: Phase 0**

진행 원칙:

- 단계는 순서대로 진행한다. 완료 기준을 통과하기 전에는 다음 단계 기능을 시작하지 않는다.
- 작업량은 집중 작업일 기준 추정치다.
- 브랜치와 배포 규칙은 `docs/SPEC.md` §3.1을 따른다. Phase 1에서 전환하기 전까지 `gh-pages` 브랜치와 라이브 사이트는 건드리지 않는다.

## 현재 상태 (2026-11-23 진단)

| 항목 | 상태 |
|---|---|
| 라이브 사이트 | `gh-pages` 브랜치의 2025-12-17 초기 골격 (원격 확인) |
| 빌드 | `npm run build` 실패 (타입 에러 2개), lint 에러 9개 |
| 미완성 페이지 | About, Archive, Portfolio가 빈 페이지 |
| 동작하지 않는 UI | 검색창, 언어 선택, GitHub/LinkedIn 링크 |
| 관리자 | 초안이 목록에 보이지 않음, 한글 제목은 slug 생성 불가 |
| 글 수, 카테고리 | 확인 못 함 (DB export 필요) |

**기존 SPA의 버그는 고치지 않는다.** 이전하면 사라질 코드이기 때문이다. 예외는 데이터 export에 필요한 작업뿐이다.
