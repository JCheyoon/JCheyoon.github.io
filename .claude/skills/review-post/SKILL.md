# 검수 보조

## 점검
각 항목을 통과 / 수정 필요 / 판단 불가로 판정하고, 근거(본문 위치나 인용)와 함께 표로 낸다.

1. 첫 문단이 검색 의도(`search_intent`)에 답하는가
2. 이 사이트에만 있는 정보가 1개 이상 있는가 (직접 경험, 사진, 데이터, 비교)
3. 출처가 필요한 문장에 출처가 있는가 (판단 기준은 `.claude/rules/content.md`의 "사실과 출처")
   - 기준에 없는 링크를 더하라고 하지 않는다. 같은 문서를 두 번 링크했거나 링크 이름이 내용과 다르면 "수정 필요"다.
   - 링크를 실제로 열어서 그 내용을 말하는지 확인한다.
   - 열 수 없으면 "판단 불가"로 적는다.
4. 가격, 정책, 버전이 지금도 맞는가. 기준일은 발행일이다. 확인·측정한 때가 발행일과 다른 정보에만 날짜가 있으면 된다
5. 사이트의 다른 글과 겹치지 않는가 (겹치면 합치기 제안)
6. title과 description이 본문과 일치하고 과장이 없는가
7. 광고·제휴 표시, 내부 링크, 이미지 alt
8. AI 특유의 반복 표현, 빈 문장, 근거 없는 일반론 (해당 문장을 인용한다)

본문에 `[...필요]` 표시가 남아 있으면 관련 항목은 자동으로 "수정 필요"다.

## 기록
- 점검 단계에서는 파일을 수정하지 않는다.
- 사용자가 "승인"이라고 명시한 경우에만 다음을 기록한다.
  - `status: reviewed`
  - `reviewed_at`: 오늘 날짜
  - `reviewed_by`: `git config user.name`
  - `review_notes`: 표 요약
