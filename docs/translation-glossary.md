# 번역 표현집 (한국어 → 영어)

작성자가 검수를 마친 **최종 글에 남은 표현**만 적는다. 번역하기 전에 읽고, 같은 말이나 비슷한 말이 나오면 이 표현을 먼저 쓴다. 문맥에 맞게 시제와 인칭은 바꾼다.
번역을 승인받은 뒤 최종 번역문과 대조해 이 표를 고친다. 제안했지만 작성자가 바꾸거나 지운 표현은 남기지 않는다.
원어민 검수를 받은 목록은 아니다.
