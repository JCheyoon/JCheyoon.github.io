# 초안 작성

규칙은 `.claude/rules/content.md`를, frontmatter는 `docs/SPEC.md` §5를 따른다.

## 입력
다음 네 가지가 모두 필요하다. 빠진 것이 있으면 먼저 질문한다.
- 주제
- 대상 독자
- 검색 의도
- 작성자의 경험이나 메모

## 절차
1. `src/content/posts/`에서 같은 주제의 글을 찾는다.
   겹치는 글이 있으면 멈추고 그 글을 보강하자고 제안한다.
2. 개요를 먼저 보여 주고 확인을 받는다.
   첫 문단에서 검색 의도에 바로 답하도록 구성한다.
3. `src/content/posts/<slug>.md`를 만든다.
   - `status: draft`, `ai_assisted: true`
   - `audience`, `search_intent`, `created_at`을 채운다.
   - slug는 영문으로 제안하고 사용자 확인을 받는다.
4. 표시를 남긴다.
   - 경험이 필요한 자리: `[경험 추가 필요: 무엇]`
   - 출처가 없는 사실: `[출처 확인 필요]`
5. 이미지가 필요하면 자리를 표시하고, 파일은 작성자가 넣게 한다(SPEC §5.4).
   - 예: `[경험 추가 필요: 실행 결과 스크린샷 → src/assets/posts/<slug>/result.png]`
   - 이미지를 만들거나 외부 이미지 주소를 쓰지 않는다.

## 하지 않는 것
- 경험, 사례, 수치를 지어내기
- 출처 없는 수치 쓰기
- 다른 글의 문장 옮기기
- 한 번에 2편 이상 만들기
- status 바꾸기

## 출력
- 파일 경로
- 남은 `[...필요]` 표시 목록
- 작성자가 보완할 일 3가지 이내
