# 콘텐츠 규칙 (모든 작업에 적용)

frontmatter 필드와 검증 규칙은 `docs/SPEC.md` §5에 있다.

## 상태와 발행
- 상태는 draft → reviewed → published 세 가지만 쓴다.
- AI가 만든 초안은 반드시 `status: draft`, `ai_assisted: true`로 시작한다.
- 원문의 `ai_assisted`는 작성자가 직접 고쳐 쓰고 검수했을 때만 작성자의 결정으로 false로 바꾼다. AI가 먼저 false로 바꾸지 않는다. 번역본은 항상 true다(화면에 번역 안내가 보인다, SPEC §5.1).
- AI는 사용자가 대화에서 "승인"이라고 명시하기 전에는 status를 reviewed로 바꾸지 않는다.
- published로는 `publish-post` 스킬을 통해서만 바꾼다.
- 정기적인 자동 생성이나 예약 발행을 하는 스크립트, 워크플로, 스케줄을 만들지 않는다.
- 초안은 요청 1회에 1편만 만든다. 발행은 주 3편을 넘기지 않는다.

## 번역과 소셜 게시
- 번역본도 AI 초안이다. `status: draft`로 만들고, 그 언어를 읽을 수 있는 사람이 검수한 뒤에만 발행한다.
- 번역은 한 번에 원문 1편, 언어 1개만 만든다.
- 번역 초안은 `publish-post`가 원문을 발행할 때 만들고, 원문과 번역본은 PR 하나로 함께 발행한다(SPEC §9.2). 생성은 자동이어도 발행은 작성자가 번역본을 검수한 뒤에만 한다.
- 초안과 번역 초안 파일은 블로그 MCP 서버 도구(`create_draft`, `translate_post`)로 만든다. 도구가 draft 상태와 규칙을 강제한다(SPEC §9.4).
- LinkedIn은 영어 글 중 작성자가 고른 글만 올린다. 영어 글의 기본값은 `linkedin: false`이고 작성자가 `true`로 바꾼다. AI는 작성자가 직접 요청하지 않으면 `true`로 바꾸지 않는다(SPEC §9.3).
- 게시 문구(`linkedin_text`, 없으면 제목과 description)는 발행 PR에서 사람이 검수한다.
- 자동 게시는 `master`에 merge된 글만 대상으로 한다.
- 게시 순서는 사이트 발행이 먼저이고, 소셜 게시가 나중이다.

## 사실과 출처
- 출처 링크가 필요한지는 이렇게 판단한다: **그 문장이 틀리면 글의 결론이 흔들리거나, 독자가 잘못된 결정을 하는가.**
  - 단다: 수치, 가격, 사용 한도 / 바뀔 수 있는 서비스 정책 / 글의 결론이 걸린 도구의 동작 / 남의 말 인용이나 남의 측정값
  - 달지 않는다: 작성자가 겪은 일, 의견, 선택한 이유 / 대상 독자가 이미 아는 기본 개념 / 도구의 널리 알려진 특징 / 같은 글에서 이미 링크한 문서
- 한 문서는 글에서 처음 나올 때 한 번만 링크한다. 링크 이름은 열었을 때 나오는 내용과 같아야 한다.
- 링크가 필요한데 출처를 찾지 못하면 `[출처 확인 필요]`를 남기고, 내용을 지어내지 않는다.
- 가격, 정책, 버전처럼 바뀔 수 있는 정보의 기준일은 글의 발행일(고친 글은 수정일)이다. 화면에 날짜가 보이므로 문장마다 "(YYYY-MM-DD 기준)"을 붙이지 않는다. 확인하거나 측정한 때가 글의 날짜와 다를 때만 그 날짜를 적는다. 발행할 때 지금도 맞는 정보인지 확인하고, 나중에 내용을 고치면 `updated_at`을 기록한다.
- 경험, 사진, 측정값은 작성자가 준 메모에 있는 것만 쓴다. 없으면 `[경험 추가 필요]`를 남긴다.

## 저작권
- 다른 글의 문장을 길게 옮기지 않는다.
- 인용은 필요한 1~2문장만, 따옴표와 출처를 함께 단다.
- 이미지는 직접 만든 것이나 라이선스를 확인한 것만 쓴다.

## 광고·제휴 표시
- 제휴 링크나 협찬이 있는 글은 frontmatter `disclosure`를 채운다.
  레이아웃이 이를 제목 바로 아래에 표시한다.
- 문구에는 대가 관계를 구체적으로 쓴다.
  예: "이 글의 쿠팡 파트너스 링크로 구매하면 작성자가 수수료를 받습니다."
- 'sponsored', 'partner', '소정의 수수료를 받을 수 있음' 같은 모호하거나 조건부인 표현은 쓰지 않는다.
- 근거: 공정위 추천·보증 심사지침. 원문 조항 대조와 쿠팡 파트너스 지정 문구는 확인이 필요하다.

## 품질
- 글 수 목표를 두지 않는다.
- 기존 글과 겹치면 새 글 대신 기존 글 보강을 제안한다.
